# 公安联网备案网址与办理流程

本文记录 Next Typecho 博客办理公安联网备案时使用的网址、准备材料、平台填写顺序、审核后的站点接入和后续维护方式。

## 1. 官方办理入口

当前统一使用全国互联网安全管理服务平台：

- 平台首页：<https://beian.mps.gov.cn/>
- 登录方式：点击“用户登录”，通过公安部“互联网+政务服务”平台完成登录。
- 业务路径：`业务办理 -> 网站业务 -> 新办网站申请`
- 结果查询：`我的 -> 我的网站 -> 详情 -> 下一步`

部分旧办事指南仍使用 `www.beian.gov.cn`，实际办理时优先使用 `beian.mps.gov.cn`。

公安联网备案与工信部 ICP 备案不是同一事项。网站完成 ICP 备案并正式联网后，还需要按要求办理公安联网备案。依据公安部第 33 号令相关规定，应在网络正式联通之日起 30 日内办理。

## 3. 备案前准备

提交前准备以下信息或电子材料：

| 材料或字段 | 说明 |
| --- | --- |
| 主体信息 | 个人或单位的真实主体信息 |
| 负责人证件 | 按平台当时要求准备正反面、手持照片或在线核验 |
| 域名证书 | 从域名注册商控制台下载，持有人应与备案主体保持一致 |
| ICP 备案信息 | ICP 备案号、主办单位、网站名称应与现状一致 |
| 服务器信息 | 公网 IP、服务器所在地、服务商名称 |
| 网络接入服务商 | 按云服务器订单、合同或控制台显示的主体名称填写 |
| 域名注册服务商 | 按域名控制台或域名证书显示的主体名称填写 |
| 网站安全负责人 | 个人站通常按平台要求填写本人信息 |
| 网站应急联络人 | 个人站通常按平台要求填写本人信息 |
| 联系方式 | 可接收审核短信和电话的手机、邮箱 |
| 网站开通日期 | 按网站实际正式联网时间填写 |
| 网站服务内容 | 个人博客、文章发布、技术分享和日常随笔 |

证件号码、手机号、住址、手持证件照等敏感数据不得写入本仓库，只在公安备案平台中提交。

## 4. 平台办理步骤

1. 打开 <https://beian.mps.gov.cn/>，点击“用户登录”。
2. 使用公安部“互联网+政务服务”平台账号登录并完成必要的实名核验。
3. 首次办理时新增“开办主体”，按个人或单位的真实情况填写主体信息。
4. 进入 `业务办理 -> 网站业务 -> 新办网站申请`。
5. 填写网站名称、域名、首页 URL、服务内容、开通日期和 ICP 备案信息。
6. 填写服务器公网 IP、服务器所在地、网络接入服务商和域名注册服务商。
7. 填写网站负责人、安全负责人和应急联络人信息。
8. 上传平台要求的证件、域名证书及其他电子材料。
9. 阅读安全责任告知或信息网络安全保护相关说明，确认后提交。
10. 通过短信和平台消息查看受理、补正、审核或办结结果。

平台字段和材料要求可能随地区、主体类型和业务类型变化，应以提交页面和属地公安机关网安部门的要求为准。

## 5. 审核退回处理

常见退回原因和处理方式：

| 原因 | 处理方式 |
| --- | --- |
| 域名持有人与主体不一致 | 更正域名实名信息，或按要求补充关系证明 |
| ICP 信息不一致 | 先在工信部备案侧完成变更，再重新提交 |
| 接入商名称错误 | 使用云服务器订单、合同或控制台中的公司全称 |
| IP 或服务器所在地错误 | 以生产服务器公网 IP 和云服务商地域为准 |
| 网站名称或服务内容不清楚 | 使用实际博客名称，并准确描述个人博客内容 |
| 联系人无法核验 | 更换为本人可接听电话并留意审核短信 |
| 材料模糊或过期 | 重新上传清晰、完整、有效的材料 |

收到补正要求后，应在原申请中修改，不要无故重复创建多条网站申请。

## 6. 审核通过后的操作

审核完成后：

1. 登录平台。
2. 进入 `我的 -> 我的网站`。
3. 选择已经通过的网站，点击 `详情 -> 下一步`。
4. 下载公安备案编号图标。
5. 复制平台生成的备案编号 HTML 代码。
6. 将图标和备案编号放在网站 Footer 底部。
7. 保持备案编号链接指向平台生成的查询地址，不要自行猜测查询 URL。

Footer 推荐同时展示：

```text
ICP备案号
公安联网备案图标 + 公安备案号
Powered by Next.js
```

备案号尚未审核通过时，不要伪造编号或查询链接。可以先预留 Footer 组件位置，拿到平台生成的信息后再上线。

## 7. 项目接入位置

本项目采用主题架构，各主题 Footer 可能分别实现。接入公安备案信息时应先搜索：

```bash
rg -n "Powered by|ICP|备案|Footer" src/themes src/components
```

建议把备案数据抽成统一配置，再由 Default、Handsome、Lite 和 Paper 等主题共同读取，避免每个主题手工维护不同编号。

推荐配置字段：

```ts
type FilingConfig = {
  icpNumber?: string;
  icpUrl?: string;
  publicSecurityNumber?: string;
  publicSecurityUrl?: string;
  publicSecurityIconUrl?: string;
};
```

公安备案图标应存放在项目静态资源目录或持久化资源目录中，不要引用临时下载地址。

## 8. 上线验证

接入后分别验证桌面端和移动端：

```bash
curl -I https://www.farisni.com/
curl -L https://www.farisni.com/ | rg "备案|beian"
```

浏览器检查项：

- 首页底部能看到完整备案号。
- 公安备案图标清晰且与文字对齐。
- 点击公安备案号能进入平台生成的查询页面。
- 手机端没有溢出、截断或遮挡。
- 裸域跳转到主域名后仍能看到备案信息。
- 深色和浅色主题下文字均可辨认。

## 9. 后续变更维护

出现以下变化时，应登录平台检查是否需要变更备案：

- 域名、网站名称、网站服务内容发生变化。
- 主体、负责人、安全负责人或应急联系人发生变化。
- 服务器公网 IP、服务器所在地或网络接入服务商发生变化。
- 网站停止服务或域名不再使用。

项目部署脚本只负责应用、Nginx 和 HTTPS，不会自动修改公安备案平台中的信息。服务器迁移或域名切换后，应把“代码部署”和“备案信息变更”作为两项独立工作处理。
