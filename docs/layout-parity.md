# 本地与生产排版一致性

## 现象

同一个 Lite 主题在本地和生产环境的文章页面出现不同的容器宽度、页面密度和文章底部区域排版。

## 原因与约束

构建产物不是原因：本地与服务器的 `BUILD_ID` 相同，线上加载的 CSS 也与本地构建产物一致。差异来自 SQLite 中的站点运行时设置：

- 本地 `data/dev.db`：`active_theme=lite`、`box_model=1`
- 生产 `data/prod.db`：`active_theme=lite`、`box_model=0`

`box_model` 对应后台“基本设置 → 紧凑/舒展模式”。它只应该影响 Handsome 主题；此前 Lite 主题也复用了 `handsome-box-model` class，导致旧的 Handsome 规则泄漏到 Lite 网格，造成文章区域偏移。生产数据库与本地数据库是独立的，部署脚本不会覆盖生产 `data/`，因此代码同步不会自动同步该设置。

## 处理方案

Lite 固定携带 `handsome-box-model` class，直接保持当前本地紧凑结构；`box_model` 为 `0` 或 `1` 都不会改变 Lite 的页面网格。默认值统一为 `1`，Handsome 主题仍可使用该开关控制密度。

## 验证结果

已核对本地与生产的构建版本、主题名称和自定义 CSS，并通过本地生产构建与线上宽屏页面复现了网格差异。Lite 现在固定使用本地紧凑结构。

## 后续风险

主题配置、站点基本设置和文章数据属于生产运行时状态，不随代码部署同步。后续如果需要“本地预览完全复现生产”，还需要同时导出/核对这些设置，而不只是比较 `.next` 文件。
