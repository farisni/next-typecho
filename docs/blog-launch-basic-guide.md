# 博客网站上线基本流程

本文面向第一次上线个人博客的场景，记录从购买服务器到完成备案的最基本步骤。当前项目使用阿里云中国内地轻量应用服务器，因此示例入口以阿里云为主。

## 流程总览

```text
购买轻量应用服务器
  -> 申请域名并完成实名认证
  -> 准备 DNS 解析
  -> 完成 ICP 备案
  -> DNS 正式指向服务器
  -> 部署网站并配置 HTTPS
  -> 完成公安联网备案
  -> 展示备案号并检查上线状态
```

## 1. 购买轻量应用服务器

选择一台带固定公网 IP 的轻量应用服务器。它适合个人博客、单机网站和小型应用，通常从基础套餐开始即可，后续再根据访问量升级。

购买前重点确认：

- 轻量应用服务器位于中国内地时，网站需要进行 ICP 备案。
- 购买时选择 Linux 系统镜像，方便部署 Node.js、Nginx 和 SQLite。
- 套餐需要满足阿里云当时的备案条件。
- 套餐应包含固定公网 IPv4、可用带宽和足够的月流量。
- 保存服务器公网 IP、地域、服务商名称和订单信息。

申请入口：

- [阿里云轻量应用服务器](https://www.aliyun.com/product/swas)
- [阿里云轻量应用服务器新手指引](https://help.aliyun.com/zh/simple-application-server/getting-started/getting-started)

## 2. 申请域名

搜索并购买未被注册的域名，然后创建域名信息模板并完成实名认证。

注意事项：

- 域名实名主体尽量与 ICP 备案主体一致。
- 下载并保存域名证书，后续公安联网备案可能需要。
- 域名不要临近到期，建议开启到期提醒或自动续费。

申请入口：

- [阿里云域名注册](https://wanwang.aliyun.com/domain)

### 域名证书在哪里找

公安联网备案中要求的“域名证书”，通常是**域名注册/持有证明**，不是 HTTPS 使用的 SSL 证书。

如果域名是在阿里云购买的，下载路径是：

1. 登录[阿里云控制台](https://home.console.aliyun.com/)。
2. 进入“域名与网站”。
3. 点击“域名列表”，找到 `farisni.com`。
4. 点击进入域名详情页。
5. 在左侧菜单点击“域名证书下载”。
6. 下载证书文件，提交公安联网备案时按平台要求上传。

也可以直接进入[阿里云域名控制台](https://dc.console.aliyun.com/)，再按“域名列表 -> farisni.com -> 域名证书下载”操作。

域名证书一般应能看到域名、域名持有人、注册商和注册有效期等信息。当前备案主域名为 `farisni.com`，优先下载该域名的证书，并确认域名持有人信息与备案主体一致。

不要把以下文件当作域名证书：

- Nginx 使用的 `fullchain.pem`、`.pem` 或 `.key` 文件，这是 HTTPS 证书和私钥。
- DNS 解析截图，这只能证明域名解析配置。
- SSL 证书申请中的 DNS/TXT 验证记录，这只是证书签发验证材料。

如果域名详情中没有下载入口，可以在阿里云控制台搜索“下载域名证书”，或联系域名注册商客服获取正式的域名注册证明。

### 子域名说明

购买的是主域名，例如 `farisni.com`。在这个主域名下，可以按业务需要使用不同的子域名：

| 名称 | 最终域名 | 常见用途 |
| --- | --- | --- |
| 裸域 | `farisni.com` | 不带前缀的主域名 |
| `www` 子域名 | `www.farisni.com` | 主网站 |
| `blog` 子域名 | `blog.farisni.com` | 独立博客 |
| `admin` 子域名 | `admin.farisni.com` | 独立管理入口 |
| `api` 子域名 | `api.farisni.com` | API 服务 |
| 通配子域名 | `*.farisni.com` | 匹配任意未单独配置的一级子域名 |

规划子域名时注意：

- `www` 本质上也是一个子域名。
- 购买 `farisni.com` 后，通常不需要再单独购买 `www.farisni.com`、`blog.farisni.com` 等子域名。
- 子域名仍需通过 DNS 解析到服务器或目标服务。
- DNS 只负责把域名指向服务器，不能代替 Nginx 的站点配置。
- 新增子域名后，应在 Nginx 的 `server_name` 中加入该域名。
- HTTPS 证书必须覆盖新增子域名，否则浏览器会提示证书不匹配。
- 普通证书需要逐个包含域名；`*.farisni.com` 通配符证书不会自动覆盖裸域 `farisni.com`。
- 如果 `farisni.com` 已经完成 ICP 备案，通常不需要为其下的二级子域名单独申请 ICP 备案，也不需要单独购买子域名。
- 如果主域名备案不在当前服务器接入商，仍可能需要做接入备案；如果主体、网站内容、服务商或服务器信息发生变化，应在原备案平台办理相应变更。
- 子域名用于完全独立的网站、后台或 API 时，仍应确保内容和运营主体属于已备案主体，并按当前接入商和属地管局要求确认是否需要补充网站信息。

当前博客推荐保持简单：

| 域名 | 建议 |
| --- | --- |
| `www.farisni.com` | 作为唯一主站地址 |
| `farisni.com` | 访问后跳转到 `www` |
| `savor.farisni.com` | 旧域名继续跳转到主站 |
| 其他子域名 | 有明确业务时再新增 |

## 3. 配置 DNS

DNS 用于把域名解析到服务器公网 IP。

### 当前权威 DNS 服务器

当前域名使用阿里云 DNS，权威 DNS 服务器为：

```text
vip1.alidns.com
vip2.alidns.com
```

这两个地址属于域名的 NS（Name Server）配置，应在域名注册商的 DNS 服务器设置中填写。域名注册商只负责指定“由谁提供解析”，具体的 `@`、`www`、`blog` 等 A/CNAME 记录，再到对应的阿里云云解析 DNS 控制台中配置。

如果域名已经显示这两个 DNS 服务器，不需要重复修改 NS，只需要进入解析设置添加记录。不同域名或账号可能被分配到不同的权威 DNS 地址，应以 DNS 控制台当前显示的地址为准。

最基本的两条记录：

| 记录类型 | 主机记录 | 记录值 |
| --- | --- | --- |
| `A` | `@` | 服务器公网 IPv4 |
| `A` | `www` | 服务器公网 IPv4 |

其中：

- `@` 表示裸域，例如 `farisni.com`。
- `www` 表示 `www.farisni.com`。
- 正式上线时可以让裸域跳转到 `www`，只保留一个主站地址。

子域名同样通过主机记录配置，最常见的解析方式：

```text
A 记录：blog.farisni.com -> 服务器公网 IPv4
CNAME：blog.farisni.com -> 另一个完整域名
```

`*` 主机记录表示泛解析，只匹配没有单独配置的子域名，不等于裸域 `@`。同一个主机记录通常不能同时配置互相冲突的 `A` 和 `CNAME`。

中国内地服务器应先完成 ICP 备案，再通过域名正式对外提供网站服务。备案前可以准备解析记录，但不要提前公开运营网站。

申请入口：

- [阿里云云解析 DNS 控制台](https://dns.console.aliyun.com/)
- [阿里云添加网站解析说明](https://help.aliyun.com/zh/dns/pubz-add-website-parsing)

## 4. 完成 ICP 备案

ICP 备案是中国内地服务器对外提供网站服务前需要完成的备案。通常通过服务器所属云厂商提交，不是直接在工信部网站上传材料。

基本操作：

1. 登录服务器所属云厂商的备案系统。
2. 选择首次备案、接入备案或新增网站。
3. 填写备案主体、网站名称、域名和服务器信息。
4. 按要求完成身份核验并上传材料。
5. 等待云厂商初审、短信核验和管局审核。
6. 审核通过后保存 ICP 备案号。

申请与查询入口：

- [阿里云 ICP 备案](https://beian.aliyun.com/)
- [工业和信息化部政务服务平台 ICP/IP 地址/域名信息备案管理系统](https://beian.miit.gov.cn/)

ICP备案通过后，应把备案号放到网站 Footer，并链接到工信部备案查询入口。

## 5. 部署网站并配置 HTTPS

将博客应用部署到服务器，使用 Nginx 反向代理应用端口，并为域名申请 HTTPS 证书。

最基本的服务器结构：

```text
浏览器
  -> DNS
  -> Nginx（80/443）
  -> Next.js（本机应用端口）
  -> 数据库
```

上线前确认：

- 防火墙或安全组开放 `80` 和 `443`。
- 应用端口只监听本机，不直接暴露到公网。
- HTTP 自动跳转 HTTPS。
- 裸域和其他旧域名统一跳转到主域名。
- HTTPS 证书覆盖实际使用的全部域名。

证书入口：

- [Let's Encrypt](https://letsencrypt.org/)
- [Certbot](https://certbot.eff.org/)

本项目的实际部署方式见：[部署说明](deployment.md)。

## 6. 完成公安联网备案

网站完成 ICP 备案并正式联网后，应按要求办理公安联网备案。根据相关规定，应在网络正式联通之日起 30 日内办理。

基本操作：

1. 登录全国互联网安全管理服务平台。
2. 新增网站开办主体。
3. 进入 `业务办理 -> 网站业务 -> 新办网站申请`。
4. 填写网站、域名、服务器、接入商和负责人信息。
5. 准备域名证书。阿里云路径为：`域名与网站 -> 域名列表 -> farisni.com -> 域名证书下载`。
6. 上传平台要求的证件及域名材料。这里上传的是域名注册/持有证明，也就是域名证书，不是 SSL 证书。
7. 提交后等待属地公安机关审核。
8. 审核通过后下载备案图标并复制备案编号 HTML。
9. 将公安备案图标、备案号和查询链接放到网站 Footer。

申请入口：

- [全国互联网安全管理服务平台](https://beian.mps.gov.cn/)

详细操作见：[公安联网备案网址与办理流程](public-security-filing-guide.md)。

## 7. 上线检查

全部完成后检查：

- `https://主域名` 可以正常访问。
- HTTP 会自动跳转 HTTPS。
- 裸域和 `www` 的跳转关系符合预期。
- HTTPS 证书有效且域名匹配。
- 首页、文章页、后台和静态图片可以正常访问。
- Footer 已展示 ICP 备案号。
- Footer 已展示公安备案图标和备案号。
- 两个备案号都链接到对应的官方查询页面。
- 手机端没有横向溢出或备案信息遮挡。
- 服务器、数据库和上传文件已经配置备份。
